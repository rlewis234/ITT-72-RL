# TV Show Search | Final Project

## 1. What App Does
My app allows users to search for TV shows and allows for filtering results.

## 2. Which option you chose: API App or Prototype
API app

## 3. What features you completed
* Searching
* Loads a default search of 'Bones' to show loading information on App start
* Sorting Results by title, Rating, Year Premiered, and Network
* Filtering results by Genre, Language, Minimum Rating, Status(If show is still running or if it ended), and Year Premiered
* Genre and Language filter options created dynamically based on search results
* Allows sorting by Ascending or Descending
* Error Message for blank searches 
* Light/Dark theme toggle

## 4. Any known issues
* API returns limited results requiring user to enter more exact search inputs
* Switching between light and dark modes has unsmooth animation on cards

## 5. How to run the app
Enter search terms in the search box, due to the API returning limited results more exact search terms may be needed to find specific shows (example: 'This Old House' will not be displayed if user searches 'House' )
